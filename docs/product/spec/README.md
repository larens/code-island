# Spec / 功能规格与业务规则

业务规则、功能说明和流程规范。

---

## English

Store functional specifications, business rules, and workflow definitions here. Each spec should describe a specific feature's behavior, edge cases, and constraints. Examples: hook protocol spec, session lifecycle rules, sound pack format.

## 中文

在此存放功能规格、业务规则和流程定义。每份规格应描述特定功能的行为、边界情况和约束条件。例如：hook 协议规格、会话生命周期规则、sound pack 格式。

---

**Note:** Specs should be implementation-agnostic. Link to architecture docs in `../dev/architecture/` for technical details.
