# PRD / 产品需求文档

存放产品需求文档（PRD）。

---

## English

Store Product Requirements Documents (PRDs) here. Each PRD should be a self-contained markdown file describing the feature motivation, user stories, acceptance criteria, and scope. Name files descriptively, e.g., `ssh-remote-support.md`, `buddy-detach.md`.

## 中文

在此存放产品需求文档（PRD）。每份 PRD 应为独立的 markdown 文件，包含功能动机、用户故事、验收标准和范围。文件命名应清晰描述功能，例如 `ssh-remote-support.md`、`buddy-detach.md`。

---

**Note:** Use markdown format. Link to related specs in `../spec/` and design assets in `../ued/` when applicable.
