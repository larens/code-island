# UED / 设计资源

设计稿链接、原型和交互说明。

---

## English

This folder is for design-related assets: links to Figma/Sketch files, interaction specs, animation guidelines, and UI mockups. Since design files are typically large binaries, prefer linking to them rather than storing them directly.

## 中文

此文件夹存放设计相关资源：Figma/Sketch 文件链接、交互规格、动画规范和 UI 稿。由于设计文件通常体积较大，建议以链接形式引用而非直接存放。

---

**Note:** Store links in markdown files, not binary files. For example: `![Notch UI](https://figma.com/file/xxx)`.
