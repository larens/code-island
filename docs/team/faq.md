## Setup / 安装

### Q: How do I grant Accessibility permissions?
**A:** On first launch, macOS will prompt you. If you missed it, go to System Settings > Privacy & Security > Accessibility and add Code Island.

### Q: Code Island doesn't appear in the menu bar after launch.
**A:** Check that you're running macOS 14+. If the app is sandboxed, it may need a moment to initialize. Try right-clicking the dock icon.

## Development / 开发

### Q: How do I run the test suite?
**A:** Run `./scripts/test.sh` from the repo root. See README.md > Testing for details.
