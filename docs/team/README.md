# Team / 跨团队文档

产品和研发团队共同维护的通用文档。

---

## English

This folder contains cross-team documentation maintained by both product and engineering: changelogs, FAQs, and collaboration guidelines. Everyone on the team should feel ownership over these files.

## 中文

此文件夹包含产品和研发团队共同维护的通用文档：版本日志、常见问题和协作规范。团队中的每个人都应共同维护这些文件。

---

**Note:** For version release notes, maintain `changelog.md`. For questions that recur, add them to `faq.md`.
