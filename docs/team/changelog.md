# Changelog / 版本发布日志

记录每个版本的功能变更、修复和已知问题。

---

## English

Maintain a reverse-chronological log of all notable changes. Follow the [Keep a Changelog](https://keepachangelog.com/) format: Added, Changed, Deprecated, Removed, Fixed, Security. Link to relevant PRs and issues where possible.

## 中文

以时间倒序记录所有重要变更。遵循 [Keep a Changelog](https://keepachangelog.com/) 格式：Added（新增）、Changed（变更）、Deprecated（弃用）、Removed（移除）、Fixed（修复）、Security（安全）。尽可能关联相关 PR 和 issue。
