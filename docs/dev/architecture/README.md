# Architecture / 架构文档

架构图、技术方案和系统设计。

## English

This folder holds architecture decision records (ADRs), system diagrams, data flow charts, and technical design documents. Examples for Code Island: session lifecycle state machine, hook ingress pipeline, SSH bridge architecture, notch window management.
